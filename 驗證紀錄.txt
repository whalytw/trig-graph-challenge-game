三角函數・繪圖闖關 v1.5
驗證日期：2026-10-02

本次更新
- 求救卡依每題開始時間發放；預設第 15／25／35 秒各取得一張。
- 教師可設定首張等待 0～300 秒、後續間隔 1～300 秒、每題累積及使用上限 0～3 張。
- 未使用的卡會保留，使用時間不改變原定發卡時間；用完不再超額補發。
- 等待時按鈕顯示倒數且停用，可用時亮起並顯示可用張數。
- 每張卡產生 12 團柔邊煙霧，約 1.8 秒逐漸飄散，正確圖線同步淡入。
- 動畫期間立即鎖定區間；送出或時間到完整顯示求救解答並停止動畫。
- 換題清除卡片與動畫，重新等待首張卡；三區各自獨立。
- 舊版設定補入預設等待與間隔，保留原本求救卡上限。

本次數學與設定驗證（Node.js）
- 預設時刻前後 14.999／15、24.999／25、34.999／35 秒的發卡數正確。
- 未使用的卡累積到上限；使用後僅扣除庫存，不重置時間，也不再超額發卡。
- 0 張停用、1 張上限、首張 0 秒與自訂等待／間隔均通過。
- 首張等待與間隔的邊界值、整數限制及舊設定移轉均通過。
- 求救區間不重複、裁切及邊界鎖定、三類函數揭示與最終四捨五入仍通過。
- 原有數學與墨水驗證仍通過 916 種題型。

本次瀏覽器驗證（Chromium／模擬觸控）
- 初始按鈕停用；未達時間直接呼叫使用也不會消耗或揭示。
- 預設第 15 秒可用；使用後顯示等待；第 25／35 秒增加庫存，上限共 3 張。
- 實際計時更新可取得卡片；累積到上限後不繼續增加。
- 記錄實際繪製的曲線透明度：初始接近透明、動畫中間逐漸增加、最後為完全顯示。
- 每次有 12 團煙霧，動畫結束後停止請求影格，保留薄霧矩形與異色解答。
- 求救當下立即清除區間筆跡；起筆與跨區畫線都不能進入鎖定區；復原不退卡。
- 左區持續觸控繪圖時，右區次要觸控能使用卡片；一次接觸不重複消耗。
- 動畫中送出，3 張求救且其他區間正確時得到 51 分，動畫停止。
- 動畫中時間到，1 張求救且其他區間正確時得到 80 分，只記錄一次。
- 約 2 秒後換題，卡片／動畫清空，首張等待重新開始。
- 教師改為 2 秒等待、3 秒間隔與 2 張上限後，新學生套用、原學生仍保留舊值；重新整理保留設定。
- 0 張隱藏按鈕；首張等待 0 秒可立即使用；恢復預設回到 15 秒／10 秒／3 張。
- 深色、淺色、短視窗的畫面已檢視。
- 1920×1080、1280×720、1273×630、960×540、3840×2160：沒有整頁上下／左右捲動，工具列與送出按鈕可見，按鈕文字未溢出。
- 頁面沒有 JavaScript 錯誤。

以上為本機瀏覽器與模擬觸控驗證；本次未於教室 IFP8653／AirSync 實機測試。

三角函數・繪圖闖關 v1.4
驗證日期：2026-10-02

本次更新
- 每題預設 3 張求救卡，教師可設定 0～3 張；0 張隱藏按鈕。
- 每次隨機揭示一個尚未揭示的 π/2 區間，共 8 區間。
- 清除求救區間筆跡、顯示異色正確曲線與薄霧矩形，並鎖定該區。
- 跨越鎖定區的筆畫分開保留兩側；擦除與復原不影響解答或卡片用量。
- 求救區間計入正確作答，再乘 0.8 的使用次數次方，最後四捨五入。
- 每題重置求救卡；各區獨立；教師修改上限從下一位學生套用。

本次數學與筆跡驗證（Node.js）
- 8 區間各寬 π/2，隨機抽取不重複；全部揭示後不再抽取。
- 正向、反向、垂直、單點筆跡以及相鄰／多個鎖定區的裁切均通過。
- sin、tan 與正餘弦疊合：其餘區間畫正確時，0／1／2／3 張求救卡分別得到 100／80／64／51 分。
- 正確解答曲線僅位於對應區間，tan 分支不跨越不連續處。
- 其餘區間空白仍扣分；重複區間 ID 不會重複扣倍率。
- 以會造成「先四捨五入再扣分」差異的數據確認，只在最後四捨五入。
- 教師設定 0～3 張可用，4 張被拒絕；舊設定補入預設 3 張。
- 既有數學與墨水檢查仍通過全部 916 種題型。

本次瀏覽器驗證（Chromium／模擬觸控）
- 三區分別使用 1／2／3 張求救卡，使用次數、區間與原筆跡獨立。
- 按求救卡後即清除該區筆跡；復原不能恢復，亦不能退卡。
- 在鎖定區起筆不留痕；從外側快速跨過鎖定區不會連線穿過。
- 橡皮擦不會擦除求救解答；用完卡後按鈕停用。
- 左區持續畫圖時，右區次要觸控可使用求救卡，一次接觸只使用一次。
- 使用三張且其他區間正確時，結果與成績紀錄為 51 分，顯示 ×0.512。
- 使用一張且其他區間正確時，時間到自動評分為 80 分，只記錄一次。
- 評分約 2 秒後換題，求救區間與次數重置。
- 教師設定 0／1／2／3 張皆正常；正在遊玩的學生保留原上限；重新整理保留設定。
- 深色與淺色的求救線顏色、薄霧區域已檢視。
- 1920×1080、1280×720、1273×630、960×540、3840×2160：沒有整頁上下／左右捲動，工具列與送出按鈕在可見畫面內。
- 頁面無 JavaScript 錯誤。

數學與墨水驗證（Node.js）
- 全六星等共 916 種參數組合：正確參考圖皆得 100 分。
- 正確參考圖不會耗盡墨水，也不會觸發同 x 超過 6 個 y 的限制。
- 難度變化種類數、振幅、40 點評分、漏畫扣分與空白 0 分皆符合規則。
- 三種 y 範圍下的隨機線段、垂直線段：增量墨水長度與多值結果和原本完整掃描一致。
- 擦除路徑保留兩端並切開中間筆跡，不會連接擦除的空白。
- 新預設值、限時選項驗證、舊預設移轉、自訂設定保留、移轉只執行一次均通過。

瀏覽器輸入驗證（Chromium／模擬觸控）
- 三個不同 touch ID 同時在三區畫圖，筆跡及指標獨立。
- 左區持續畫圖時，右區的次要接觸能立即切換細筆／橡皮擦。
- 同一區仍有繪圖接觸時按復原，會結束該區筆畫並復原；另一區的繪圖持續。
- 次要手指及主要手指長按超過 1 秒，復原只操作一次；滑鼠長按也只操作一次。
- 滑鼠的一次點擊不會因後續 click 多復原一次。
- 同 x 筆跡超過 6 個 y 時耗盡墨水，使用橡皮擦後可恢復。
- 計時途中仍按住時，時間到釋放接觸並只評分一次。
- 觸控診斷顯示目前 3 點、最多 3 點、類型 touch；放開後目前歸零，最高值保留。

闖關與版面驗證
- 預設計畫為 [1,2,3,6]，每區四段進度線；自訂 [1,1,3,4] 的完成段與目前段正確。
- 最大設定 120 題的進度線仍在所屬區域內。
- 空白 0 分仍前進；評分 1.1 秒後還停在原題，約 2 秒後換題。
- 4 題成績 0、100、100、100，結算總分正確為 300 / 400。
- 1920×1080、1280×720、1273×630、960×540、3840×2160：整頁沒有上下或左右捲動，送出按鈕在可見畫面內。
- 所有 916 種公式在 1920×1080、1273×630、960×540 皆未超出題目寬度。
- x 刻度文字的位置以實際 canvas 座標確認，並檢視一般、短視窗及診斷頁截圖。
- 設定重新整理後保留；頁面沒有 JavaScript 錯誤。
